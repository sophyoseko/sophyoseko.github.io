## Site features

- **Responsive layout** for mobile, tablet and desktop, with a slide-in mobile menu
- **Smooth navigation** that highlights the section you're reading
- **Subtle scroll animations**, switched off for visitors whose device is set to reduce motion
- **Accessible:** a skip link, keyboard-friendly menu, AA-contrast colours and screen-reader labels
- **Search and sharing ready:** meta description, Open Graph and Twitter tags, and schema.org `Person` data
- **CV download** with a friendly message if the file is unavailable

## Built with

`HTML5` · `CSS3` (custom properties, Grid, Flexbox) · `Vanilla JavaScript` (IntersectionObserver) · Google Fonts (Inter, Playfair Display)
