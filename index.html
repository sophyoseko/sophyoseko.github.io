Featured · Data Platform Team capstone project

JobPulse

African Tech Job Intelligence Platform

A full-stack platform that collects African tech job postings and helps job seekers see where their skills fit: from CV upload to matched jobs and a learning plan.

  • Job data collection: scrapers across African and remote job boards, cleaned and deduplicated into a dataset of about 13,000 postings.
  • CV skill extraction: users upload a CV and an NLP skill extractor identifies their skills and skill gaps.
  • Job matching: weighted scoring that matches candidates to jobs on skills, experience and location.
  • Learning recommendations: personalised courses and interview-prep resources based on each user's skill gaps.

Featured · Recommendation System

CineMatch

Hybrid Movie Recommendation System

A movie discovery app built on the MovieLens 1M dataset (about one million ratings) and deployed with Streamlit.

  • Hybrid recommender (notebook): chooses a strategy based on each user's rating history: popularity-based for new users, content-based genre similarity for users with fewer than 20 ratings, and user-based collaborative filtering (cosine similarity) for everyone else.
  • Live web app: genre-based recommendations and a Top Rated page, both filtered to movies with enough ratings to be reliable.
  • Richer discovery: TMDb integration for posters, overviews and trailers, plus live movie search.
  • Python
  • pandas
  • NumPy
  • scikit-learn
  • Streamlit
  • TMDb API

FinTech Loan Approval Classifier
